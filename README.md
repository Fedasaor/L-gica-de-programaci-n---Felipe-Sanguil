# Generador Seguro de Contraseñas
Este es un proyecto de una aplicación de escritorio desarrollada en Python utilizando la biblioteca Tkinter. La aplicación permite a los usuarios generar contraseñas seguras y personalizadas según sus preferencias.

 ---

### Fecha 
Domingo, 24 de agosto del 2025

 ---

## Objetivo del Programa
Ayudar a usuarios de cualquier aplicación a poder obtener contraseñas que sean difíciles de hackear, lo que ayudaría grandemente a la ciberseguridad.

---

## Funcionalidades del Código
- [x] Interfaz gráfica amigable y fácil de usar.
- [x] Opción para seleccionar la longitud de la contraseña (entre 1 y 15 caracteres).   
- [x] Opciones para incluir letras, números y símbolos en la contraseña.
- [x] Validación para asegurar que la contraseña generada cumpla con los criterios seleccionados.
- [x] La contraseña generada se muestra en la interfaz y se guarda automáticamente en un archivo de texto local llamado `contraseña_generada.txt`.

 ---

## Requisitos
- Python 3.x
- Biblioteca Tkinter (generalmente incluida con la instalación estándar de Python)  

 ---

## Instalación
1. Clona este repositorio o descarga el archivo `Complete.py`.
2. Asegúrate de tener Python 3.x instalado en tu sistema.
3. Ejecuta el archivo `Complete.py` utilizando el siguiente comando en tu terminal o línea de comandos:
   ```bash
   python Complete.py
   ```
 ---

## Uso
1. Abre la aplicación.
2. Selecciona la longitud deseada para la contraseña utilizando el Spinbox.     
3. Marca las casillas para incluir letras, números y/o símbolos según tus preferencias.
4. Haz clic en el botón "Generar Contraseña".
5. La contraseña generada se mostrará en la interfaz y se guardará en el archivo
    `contraseña_generada.txt` en el mismo directorio donde se encuentra el script.
